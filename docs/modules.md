# โมดูล — สิ่งที่ทำได้ vs ยังขาดถึง V0.1.0

| โมดูล | เส้นทาง | V0.0.1 ทำได้ | ขาดก่อนใช้ทุกวันลื่น |
|--------|---------|--------------|------------------------|
| ฮับ | `/` | กริดไม่เท่ากัน, ออกจากระบบ | — |
| วันนี้ | `/today` | สรุปจ่าย / inbox / งาน / บันทึก / เตือนคลัง | — |
| จดด่วน | `/inbox` | จดข้อความ+ไฟล์, จัดไปงาน/คลัง/บ้าน/บันทึก/ทิ้ง | ปุ่มเงินยังไม่สร้างรายจ่าย |
| งาน | `/tasks` | เพิ่ม กรอง วันนี้/ค้าง/ทั้งหมด, เสร็จ/ลบ | ตารางเดสก์ท็อปยังไม่มีปุ่มลบ |
| เงิน | `/money` | จำนวนสตางค์, หมวด, ร้าน, วันที่, ใบเสร็จ, สรุปวันนี้/เดือน | ต้องมี R2 ถึงจะเก็บรูป |
| คลัง | `/vault` | ประเภท, วันหมดอายุ, ไฟล์ | ลบจากตารางเดสก์ท็อป |
| บ้าน | `/home` | ของในบ้าน, รายการซื้อ, บิลง่าย | ไม่มี recurring (ตั้งใจ) |
| บันทึกวัน | `/journal` | หนึ่งวันหนึ่งบันทึก, อารมณ์, รูป, เลื่อนวัน | — |

หมวดเงิน: อาหาร, เดินทาง, ของใช้, บิล, อื่นๆ

วันที่ใน UI เป็น พ.ศ. ปฏิทินในฟอร์มเป็น `type=date` (ค.ศ. ตามเบราว์เซอร์) เก็บ ISO
