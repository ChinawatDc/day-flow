## โมดูล
- [ ] วันนี้: จดจ่ายหรือติ๊กงานได้ในหน้า, งานค้างข้ามวันแยกกลุ่ม
- [ ] ค้นบนวันนี้เจองาน/เงิน/คลัง/จดของตัวเอง
- [ ] จดด่วน: จดแล้วจัดเป็นงานได้ แล้วกลับวันนี้
- [ ] งาน: เพิ่ม แก้ ติ๊กเสร็จ ลบ (ยืนยัน) กรองค้าง
- [ ] เงิน: บันทึกบาท แก้ได้ สรุปหมวดเดือนนี้
- [ ] คลัง: เก็บ + กรองใกล้หมดอายุ + แก้
- [ ] บ้าน: ของ / ซื้อ / บิล แก้ได้ และคัดลอกบิลเดือนที่แล้วไม่ซ้ำชื่อ
- [ ] บันทึกวัน: เขียน อารมณ์ เลื่อนวัน
