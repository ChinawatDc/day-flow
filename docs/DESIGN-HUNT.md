# Design — เลือกบ้าน (`/family/hunt`)

โมดูลนี้**คนละโทน**กับสมุดบ้าน ([DESIGN-2026.md](./DESIGN-2026.md)) ตั้งใจให้อ่านเป็นระบบ listing ไม่ใช่สมุดครัว

ใช้เฉพาะภายใต้ `.hh-shell` — อย่าใส่ `--hh-*` ในหน้าสมุด

## หลัก
- พื้น: slate เย็น (`.hh-shell`) ไม่ใช่ `--canvas` เขียว kaffir
- พื้นผิว: การ์ดทึบขอบบาง `--hh-line` ไม่ใช่ liquid glass `.df-card`
- แบรนด์โมดูล: `--hh-gold` (ทองอ่อน) สำหรับอันดับ / ราคา / chip งบที่เลือก
- ฟอนต์: Prompt + Bai Jamjuree ชุดเดียวกับแอป
- ไอคอน: Lucide เท่านั้น — ไม่มีอิโมจิ เหรียญอันดับเป็นตัวเลข
- มือถือ: การ์ด + chip + bottom tabs ของโมดูล
- เดสก์ท็อป: ตารางหนา + คอลัมน์เทียบ

## Utilities
| Class | ใช้เมื่อ |
|-------|---------|
| `.hh-shell` | รากเลย์เอาต์ทั้งโมดูล |
| `.hh-card` | บล็อกรายการ / แผง |
| `.hh-chip` / `.hh-chip-on` | กรองงบ |
| `.hh-nav` | แท็บล่างมือถือ / แถบเดสก์ท็อป |
| `.hh-table` | ตารางโครงการจอใหญ่ |
| `.hh-gold` | ตัวเลขราคา / อันดับ |

## ห้าม
`.df-card` · `.df-card-hero` · kaffir เป็นปุ่มหลัก · bottom nav สมุด · อิโมจิเหรียญ · Inter
